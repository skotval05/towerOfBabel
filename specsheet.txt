=================================================================

      ACT I: INTRODUCTIONS AND GENERAL SPECIFICATIONS

=================================================================

The Tower of Babel is a 16-bit CPU architecture designed by yours truly.
Conceptualized in the Summer of 2022.

===== GEN SPEC =====

Architecture:   Von Neumann (single memory bank)
Bus Width:      16 bits (-32,768 to 32,767 min/max for signed ints, or 65,536 max for unsigned ints)
ALU ops:        add/subtract, logical and circular shifts left and right, boolean ops AND, OR, NOT, XOR
Registers:      8 GP registers addressable via load/store/swap/operate commands. A B C D E F G H. simple enough.
Flow Control:   Absolute jump options (to inst 30) and relative jumping options (forward 30 inst).
Byte Length:    16 bits.

===== INSTRUCTION LAYOUT =====

16 bit instruction looks like this
XXXX XXXX XXXX XXXX

reformat it to allocate bits to different parts of instruction like so
IIIIII-AAA-BBB-NN-J-R

where the I group represents a six-bit opcode which determines the operation to execute.
where the A group represents a register for operand A (0 = A, 1 = B, 2 = C, so on)
where the B group represents a register for operand B (same rules apply here)
where the N group represents the number of words to increment. (00 = 0, 01 = 1, 10 = 2, 11 = 3). 
where the J group represents a true/false statement on whether or not the instruction is a jumping one. This is always zero except for some explicit cases in O-group 6.
where the R group represents a true/false statement on whether or not the instruction is a branching one. We do not care what this is unless J is 1.

=================================================================

                   ACT II: INSTRUCTION SET

=================================================================

The instruction set is broken up into eight sections, each with eight instructions.
This splits the I-group above into two subgroups: Overarching and Underarching. (IIIIII -> OOO-UUU)
Each O-group will be organized so that, when possible, all related U-group values are processed in the same place.

===== O-GROUPS =====

000: Memory Operations
001: Arithmetic Operations
010: Logic Operations
011: Unused
100: Unused
101: I/O Operations
110: Flow Control Operations
111: Miscellaneous Operations

===== U-GROUPS =====

=== O-GROUP 000 === MEMORY

000: MOV regA, regB         : Moves the value at regB into regA                                 NN = 01 "MOVe"
001: LDA regA, regB         : Loads the value at M[regB] into regA                              NN = 01 "LoaD from Address"
010: STA regA, regB         : Stores the value in regB into M[regA]                             NN = 01 "STore at Address"
011: WRA regA, imm          : Writes the value in regA into M[imm]                              NN = 10 "Write Register at Address"
100: SWP regA, regB, regC   : Swaps the values of regA and regB, overwriting regC               NN = 01 "SWaP"
101: LDI regA, imm          : Loads the immediate value into regA                               NN = 10 "Load Immediate"
110: STI regA, imm          : Stores the immediate value into M[regA]                           NN = 10 "STore Immediate"
111: WII imm1, imm2         : Writes imm2 to M[imm1]                                            NN = 11 "Write Immediate to Immediate"

=== O-GROUP 001 === ARITHMETIC

000: ADD regA, regB, regC   : Adds reg values of opB and opC together, stores in regA           NN = 01 "ADD"
001: ADI regA, regB, imm    : Adds immediate and regB, stores in regA                           NN = 10 "ADd Immediate"
010: LSL regA, regB         : Shifts the value in regA one bit left  into regB                  NN = 01 "Logical Shift Left"
011: LSR regA, regB         : Shifts the value in regA one bit right into regB                  NN = 01 "Logical Shift Right"
100: SUB regA, regB, regC   : Subtracts opB from opA, and stores in regC.                       NN = 01 "SUBtract"
101: SBI imm, regA, regB    : Subtracts immediate value from regA, and stores in regC.          NN = 10 "SuBtract Immediate"
110: CSL regA, regB         : Shifts the value in regA one bit left  into regB, with wrap.      NN = 01 "Circular Shift Left"
111: CSR regA, regB         : Shifts the value in regA one bit right into regB, with wrap.      NN = 01 "Circular Shift Right"

=== O-GROUP 010 === LOGIC

000: AND regA, regB, regC   : Bitwise AND operation of regs A and B, into regC                  NN = 01 "AND"
001: ORR regA, regB, regC   : Bitwise OR  operation of regs A and B, into regC                  NN = 01 "OR"
010: NOT regA, regB         : Bitwise NOT operation (inversion) of reg A into regB              NN = 01 "NOT"
011: XOR regA, regB, regC   : Bitwise XOR operation of regs A and B, into regC                  NN = 01 "eXclusive OR"
100: OVF regA               : Passes OVERFLOW bit from flags register into regA                 NN = 01 "OVerFlow"
101: NEG regA               : Passes NEGATIVE bit from flags register into regA                 NN = 01 "NEGative"
110: CAR regA               : Passes CARRY    bit from flags register into regA                 NN = 01 "CArRy"
111: ZER regA               : Passes ZERO     bit from flags register into regA                 NN = 01 "ZERo"

=== O-GROUP 101 === I/O

000: WXR regA               : Writes value in regA to port X                                    NN = 01 "Write port X from Register"
001: WYR regA               : Writes value in regA to port Y                                    NN = 01 "Write port Y from Register"
010: WXI imm                : Writes immediate value to port X                                  NN = 10 "Write into port X Immediate"
011: WYI imm                : Writes immediate value to port Y                                  NN = 10 "Write into port Y Immediate"
100: RPX regA               : Reads value from port X into regA                                 NN = 01 "Read Port X"
101: RPY regA               : Reads value from port Y into regA                                 NN = 01 "Read Port Y"
110: SPX regA               : Stores value from port X into M[regA]                             NN = 01 "Store Port X"
111: SPY regA               : Stores value from port Y into M[regA]                             NN = 01 "Store Port Y"

=== O-GROUP 110 === FLOW CONTROL

000: JMP regA               : Sets the Program Counter to the value in regA                     NN = 00 "JuMP"
001: JIT regA, regB         : Sets the Program Counter to the value in regA if regB != 0        NN = 00 "Jump If True"
010: JZR regA, regB         : Sets the Program Counter to the value in regA if regB == 0        NN = 00 "Jump if ZeRo"
011: SPC regA               : Stores the value in the Program Counter to regA                   NN = 01 "Store Program Counter"
100: BRN imm                : Adds the immediate value to the Program Counter                   NN = 00 "BRaNch"
101: BIT regA, imm          : Adds the immediate value to the Program Counter if regA != 0      NN = 00 "Branch If True"
110: BZR regA, imm          : Adds the immediate value to the Program Counter if regA == 0      NN = 00 "Branch if ZeRo"
111: HLT                    : Hangs until the Program Counter is manually incremented.          NN = 00 "HaLT"

=================================================================

         ACT III: ASSEMBLY WORDS TO MICROINSTRUCTIONS

=================================================================

Consider that each operation may take up to eight clock cycles. This is decided arbitrarily because I do not feel like implementing a 4 bit counter. get trolled.

Each clock cycle is referred to by a three bit code. 
It is implied that alongside each list of operations, the subcounter increments.
This subcounter is tied 1:1 to the cycling of the clock.
Any "immediate" values refered to in the instruction at address N are stored at address N+1 and, if necessary, N+2.
