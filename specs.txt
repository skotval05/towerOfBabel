===== DESIGN SPECIFICATIONS =====

General Architecture:       16-bit buses.
                            500 KHz Clock.
                            Monitor TBD.
                            64 Valid Assembly Instructions.
                            25 Used  Instructions.
                            Little-Endian byte structure.
                            2^16 (65,536) Valid Memory Addresses.
                            2-byte Addresses (16-bit WORDS)

===== REGISTER MAP =====

    Register List: A, B, C, D, S, F, W, J

    [000] A -- General Purpose
    [001] B -- General Purpose
    [010] C -- General Purpose
    [011] D -- General Purpose
    [100] S -- Sum
    [101] F -- Flags
    [110] W -- Swap
    [111] J -- Jump

    A-D are general purpose, and given R/W access by default.

    S is always the data output of the ALU.         R/W access.
    F is the set of flags that come out of the ALU. No R/W access.
    -   In order of LSB -> MSB:
        Zero
        Even Parity
        Overflow
        Negative
        (The next 12 bits are always 0.)
    W is a swap register, and will be used to hold the temporary data while a SWP operation occurs. Has R/W access, but will overwrite frequently.
    J is the jump register, and stores the address to jump to during any given jumping operation. R/W access.

===== MEMORY MAP =====

0x0000 .. 0x7FFF -> PROGRAM MEMORY          (32,768 WORDS)
0x8000 .. 0xFBFC -> GP RAM                  (31,742 WORDS)
0xFBFD .. 0xFFFD -> STACK (or more GP RAM)  (1024 WORDS)
0xFFFE .. 0xFFFE -> SP (S)tack (P)ointer    (1 WORD)
0xFFFF .. 0xFFFF -> PC (P)rogram (C)ounter  (1 WORD)

===== INSTRUCTION LAYOUT =====

XXXXXX-Y-Z-II-AAA-BBB

X - 6-bit Operation Code. See bottom chart for operation-opcode assignment.
Y - 1-bit flag denoting if A is used. if Y is low, use argA as register address; else use the word at location n+1 as the value for argA.
Z - 1-bit flag denoting if B is used. if Z is low, use argB as register address; else use the word at location n+2 as the value for argB.
A - 4-bit value, sometimes used for argA register address, else unused.
B - 4-bit value, sometimes used for argB register address, else unused.
I - 2-bit value, generated by the assembler. Used to tell (words + 1) to jump for next instruction. A value of 00 will only increment one word, and a value of 11 will increment 4 words.

Instructions can be anywhere between 1 and 3 words. SWP will always be 1 word, as it only takes registers as operands. An I value of 11 shouldn't be used often, i just like 00 being default.

===== INSTRUCTION SET =====

All instructions are 6 bits long. The prefix for any category is given at the category header, followed by the sub-code.
This is so I can be even stingier with my transistor count.

EXAMPLE OPERATION : [PREFIX] [CODE]

    = MISC OPS =            PREFIX [000]

    [000] NOP               NO OPERATION
      :
    [111] HLT               STOPS CLOCK

    = ARITHMETIC OPS =      PREFIX [001]

    [000] ADD reg, imm/reg  S = reg + imm/reg
    [001] SUB reg, imm/reg  S = reg - imm/reg
    [010] DEC reg           S = reg - 1
    [011] INC reg           S = reg + 1
      :

    = BITWISE LOGIC OPS =   PREFIX [010]

    [000] AND reg, imm/reg  S =  reg & imm/reg
    [001] ORR reg, imm/reg  S =  reg | imm/reg
    [010] NOT reg           S = ~reg
    [011] EQL reg, imm/reg  S =  reg == imm/reg
      :

    = SHIFT OPS =           PREFIX [011]

    [000] LSL reg           S = reg  << 1
    [001] LSR reg           S = reg  >> 1
    [010] ASL reg           S = reg A>> 1
    [011] ALR reg           S = reg A<< 1
      :

    = JUMPING OPS =         PREFIX [100]

    [000] JMP imm/reg       PC = imm/reg
    [001] JZR reg, imm/reg  PC = (imm/reg[0] == 1) ? imm/reg : NOP
    [010] JEV reg, imm/reg  PC = (imm/reg[1] == 1) ? imm/reg : NOP
    [011] JOF reg, imm/reg  PC = (imm/reg[2] == 1) ? imm/reg : NOP
    [100] JNG reg, imm/reg  PC = (imm/reg[3] == 1) ? imm/reg : NOP
      :

    = STACK OPS =           PREFIX [101]

    [000] PSH imm/reg       PUSHES VALUE ONTO STACK, INCREMENTS SP
    [001] POP reg           POPS VALUE OFF STACK, DECREMENTS SP
    [010] TOP reg           RETRIEVE TOP VALUE OF STACK, NO SP CHANGES
      :

    = MEMORY OPS =          PREFIX [110]
    
    [000] MOV reg, imm/reg  PUSHES DATA INTO REGISTER
    [001] LDA reg, imm/reg  LOADS VALUE AT ADDRESS INTO REGISTER
    [010] LDI reg, imm/reg  LOADS VALUE INTO REGISTER
    [011] STR reg, imm/reg  STORES VALUE IN REGISTER TO LOCATION IN RAM
    [100] SWP reg, reg      SWAPS VALUES BETWEEN REGISTERS USING W AS TEMP VALUE
      :

    = A SECRET THIRD OP =   PREFIX [111]
